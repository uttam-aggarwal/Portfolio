# **App Name**: Uttam's Digital Canvas

## Core Features:

- Info Showcase: Interactive display of personal information including a concise bio, contact details (LinkedIn, email, GitHub, mobile), and a downloadable resume.
- Dynamic Content: Dynamic presentation of skills, projects, certificates, achievements, and education using visually appealing sections.
- AI Portfolio Tailor: AI-powered tool to generate personalized portfolio summaries based on the user's provided data, highlighting key skills and experiences for different job applications.

## Style Guidelines:

- Primary color: Clean white or light grey for a minimalist background.
- Secondary color: Dark grey or black for text to ensure high readability.
- Accent: Teal (#008080) to highlight key elements and calls to action.
- Use a grid-based layout for a structured and responsive design.
- Simple, line-based icons for a modern and clean aesthetic.
- Subtle transitions and animations to enhance user experience without being distracting.
